# To-Do List

A simple, responsive to-do list web app built from scratch using vanilla HTML, CSS, and JavaScript — no frameworks, no libraries.

## Features

- Add tasks
- Mark tasks as complete (click to strike through)
- Delete tasks
- Tasks persist across page reloads using `localStorage`
- Responsive glassmorphism UI with animated background elements

## Built With

- HTML5
- CSS3 (Flexbox, CSS animations, `backdrop-filter` for the glass effect)
- Vanilla JavaScript (DOM manipulation, event listeners, `localStorage`)

## What I Learned

This was a beginner project built to practice:
- DOM manipulation (creating, appending, and removing elements dynamically)
- Event handling (click events, event bubbling and `stopPropagation`)
- Persisting data in the browser with `localStorage` and `JSON.stringify`/`JSON.parse`
- CSS animations with `@keyframes` and layered `box-shadow` for depth

## How to Run

Just open `index.html` in your browser — no build step or dependencies required.
